# 🔐 Simple Login Page – HTML & CSS

This is a beginner-friendly project that showcases a **login form UI** created using only **HTML** and **CSS**. It was built as part of my early web development practice, focusing on layout, styling, and form design.

---

### ✨ Features:
- 📄 Clean and modern login form
- 🎨 Styled using pure CSS (no frameworks)
- 💻 Responsive layout (basic)
- 🧪 Ideal for frontend practice and learning form structure

---

### 🛠️ Technologies Used:
- **HTML5**
- **CSS3**

---

### Purpose of the Project:
This project was created during the early stages of my learning journey in web development. The goal was to:

Practice basic HTML form elements

Apply CSS styling techniques

Create a clean and centered login layout
